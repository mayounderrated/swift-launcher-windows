Swift Launcher 1.0

Ctrl+Space: open or hide Swift.
Type to search apps and files. Each opening clears the previous query.
All is the default filter; click the filter button or press Tab to change it.
Scroll or use Up/Down to select, Enter to open, Ctrl+Enter to reveal in Explorer.
Escape or switching to another app dismisses Swift.
Right-click the tray icon for refresh, search folders, and Exit.

Installation
Setup installs for the current Windows user in LocalAppData\Programs\Swift.
A Start menu shortcut and Windows Installed Apps uninstall entry are created.
Desktop and start-at-sign-in shortcuts are optional.
Close any older portable copy before installing.

Settings
Search folders remain in %LOCALAPPDATA%\SwiftLauncher\roots.txt.
Uninstall preserves those preferences and never deletes your indexed files.

Requirements
64-bit Windows 10/11 with .NET Framework 4.7.2 or newer.
No browser runtime or online account is required.
This personal build is unsigned.
