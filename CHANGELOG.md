# Changelog

## 2.0.0

- Added a native settings window inspired by Flow Launcher's clear category layout.
- Added dark, light, and system themes with five accent colours.
- Added configurable global shortcuts with conflict detection.
- Added default-mode, clear-on-open, animation-speed, and start-at-sign-in settings.
- Added Google search through the `g query` keyword.
- Added a local maths calculator whose selected result is copied with Enter.
- Added `settings` as a searchable launcher action.

## 1.0.0

- Initial circular Windows app and file launcher release.
